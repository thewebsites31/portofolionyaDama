Paket file website (PORTODAMA)

Perubahan utama:
- Link internal (antar halaman HTML) sekarang terbuka di tab/halaman yang sama (target="_blank" dihapus dari index.html).

Catatan penting:
1) Foto profil
   Halaman profile.html memanggil file:
   - assets/foto-profile.jpg
   Pastikan kamu menaruh foto profil dengan nama itu di folder assets/.

2) File PDF di Tugas Kelompok
   Halaman tugas-kelompok.html memanggil:
   - proposal-etika-pizza.pdf
   - laporan-kepuasan-pizza-online.pdf
   Pastikan file PDF-nya ada di folder yang sama dengan tugas-kelompok.html (root folder).

Cara pakai di GitHub Pages:
- Upload semua isi folder PORTODAMA ke repository kamu (atau salin isinya ke root repo).
- Pastikan index.html ada di root folder yang dipublish oleh GitHub Pages.
